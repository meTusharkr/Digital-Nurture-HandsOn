# Exercise 7 - Financial Forecasting

## Aim

Implement a financial forecasting application using recursion.

## Objective

Predict the future value of an investment based on:

- Current Value
- Annual Growth Rate
- Number of Years

## Algorithm

1. Read the current investment value.
2. Read the annual growth rate.
3. Read the number of years.
4. Use recursion to calculate the future value.
5. Display the predicted value.

## Formula

Future Value = Current Value × (1 + Growth Rate)^Years

## Sample Output

Input

```
Current Value : 10000
Growth Rate : 10%
Years : 5
```

Output

```
Predicted Future Value: 16105.10
```

## Conclusion

This exercise demonstrates the use of recursion to solve a financial forecasting problem based on compound annual growth.
