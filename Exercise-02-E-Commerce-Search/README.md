# Exercise 2 - E-Commerce Platform Search

## Aim

Implement a product search function using Linear Search.

## Objective

Search for a product by its Product ID.

## Algorithm

1. Store product details in an array.
2. Traverse the array.
3. Compare Product ID.
4. If found, display product details.
5. Otherwise display "Product Not Found".

## Time Complexity

- Best Case: O(1)
- Worst Case: O(n)

## Expected Output

```
Enter Product ID to search: 103

Product Found
ID : 103
Name : Shoes
Category : Fashion
```
